# ADM01_AI_Lab_Experiments
M. Tech Artificial Intelligence &amp; Data Science - SIMATS (ADM01 Artificial Intelligence Lab)


Python implementations of Artificial Intelligence algorithms, organized by unit. All experiments were executed in Google Colab and saved as (`.ipynb`) files.

## Unit I (Lab 1)
- Experiment 1: Breadth-First Search (BFS)
- Experiment 2: Depth-First Search (DFS)
- Experiment 3: Water Jug Problem
- Experiment 4: A* Search Algorithm

## Unit II (Lab 2)
- Experiment 5: 8-Queens Problem using Backtracking
- Experiment 6: Map Colouring using Constraint Satisfaction Problems (CSP)
- Experiment 7: Minimax Algorithm
- Experiment 8: Alpha-Beta Pruning

## Usage
1. Open the required `.ipynb` file in Google Colab.
2. Run the cells sequentially to view the execution and output.
